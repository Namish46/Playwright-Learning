## Git Learning

- git status → shows current working tree state
- git add → stages changes
- git commit → saves staged changes to Git history
- git log → shows commit history
- git diff → shows unstaged changes
- git branch → shows branches
- git switch → switches branches
- git merge → combines branch changes
- git push → sends commits to the remote repository
- git restore → discards working-tree changes
